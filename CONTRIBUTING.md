# Contributing

Actuarii takes issues, not pull requests, for now.

It is maintained by one person, and it governs its own development: changes to its governed files go through its own
gate, and each commit carries its record. A pull request from outside would arrive outside that channel, so changes
are made here, from the issues.

Issues that help most:

- you tried it: it worked, it failed, or the installation stopped you;
- a bug, with the steps to repeat it;
- the coding agent you would use it with, if it is not Claude Code;
- a question about how it works.

Before reporting a way around a rule, check the declared limits in [`AGENTS.md` §9](AGENTS.md#9-declared-limits):
v0.1 is not a security boundary, and what it does not cover is listed there. A way around that is not listed is worth
an issue.
